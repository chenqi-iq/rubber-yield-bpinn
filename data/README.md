# Data Description

This directory contains the processed data used in the BPINN rubber yield estimation study.

## Raw Data Sources (not included in this repository)

Due to file size and data sharing policies, raw remote sensing GeoTIFFs and large databases are not included. They can be obtained from the following public sources:

| Data | Source | Access |
|---|---|---|
| MODIS LAI (MCD15A3H V6.1) | NASA Earthdata | https://earthdata.nasa.gov/ |
| MODIS NDVI (MOD09A1 V6.1) | NASA Earthdata | https://earthdata.nasa.gov/ |
| MODIS PRI (MCD19A1 V6.1) | NASA Earthdata | https://earthdata.nasa.gov/ |
| MODIS LST (MOD11A1 V6.1) | NASA Earthdata | https://earthdata.nasa.gov/ |
| HWSD2 (soil pH, organic matter) | FAO | https://www.fao.org/soils-portal/ |
| Rubber production statistics | Hainan Provincial Bureau of Statistics | http://tjj.hainan.gov.cn/ |
| Hainan county boundaries | National Geomatics Center of China | http://www.ngcc.cn/ |

## Processed Data Files

The following processed CSV files are generated by the scripts in `../scripts/`:

| File | Description | Dimensions |
|---|---|---|
| `01b_橡胶18市县面板_农垦已分摊.csv` | County-level rubber area and production (reclamation-adjusted) | 252 rows × ~10 cols |
| `02_市县土壤PH有机质.csv` | County-level mean topsoil pH and organic matter | 18 rows × ~6 cols |
| `03_遥感月度面板_long.csv` | Monthly remote sensing zonal statistics (long format) | 3,024 rows × ~8 cols |
| `04_年度物候特征.csv` | Annual phenological features derived from monthly data | 252 rows × ~15 cols |
| `05_主表_年度面板.csv` | Final analysis table (county–year) | **252 rows × 53 cols** |
| `05b_主表_月度长面板.csv` | Final analysis table (county–month, long format) | 3,024 rows × ~20 cols |

## Sample Data

A sample subset (first 3 counties, 3 years) is provided in `sample/` for code testing purposes.

## Data Processing Pipeline

1. `step1_提取橡胶数据.py` — Extract and clean rubber statistics from Excel
2. `step2_提取土壤数据.py` — Extract HWSD2 soil properties, aggregate to county level
3. `step3_提取遥感月度数据.py` — Zonal statistics from monthly GeoTIFFs using county boundaries
4. `step4_年度物候特征.py` — Derive annual phenological features from monthly time series
5. `step5_合并主表.py` — Merge all data sources into the final analysis table
